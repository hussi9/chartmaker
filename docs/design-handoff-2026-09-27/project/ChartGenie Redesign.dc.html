What changed and why
  • Templates are the front door. Today the chart-type chooser is a two-row toolbar above the canvas; here it is a gallery of finished posts with sample numbers already inside, so the first thing a visitor sees is a result.
  • One export, one place. Export, Share and autosave live top-right on every screen. The seven header buttons collapse to two; Templates and My Charts move to the rail.
  • Chart at true post size. Format is a chip row directly above the artboard with the real pixel size shown; the canvas is the only thing with a shadow, so it reads as the product.
  • Keyboard-fast data. The Content/Style/Settings tabs become one always-visible data grid: Tab moves, Enter adds a row, a trailing empty row invites typing. Import methods are one menu.
  • Post-ready presets and handle. A "Look" strip under the artboard gives one-click Clean/Bold/Dark/Newsletter; the handle badge is on by default so every export markets the creator.
  • Return loop. The Recent shelf on Templates and the "Duplicate last month" card on My Charts make the second visit faster than the first.
