ChartGenie · holistic redesign v2

From “make a chart” to “publish a number that lands.”

The current product is a chart tool. The opportunity is a publishing tool for people with numbers: get the data in with zero friction, let the product propose the chart and the sentence, export every size at once, and make each post a door back to ChartGenie. Below: the principles, the feature map, and five screens that carry it.

Paste anything
Cells, a sentence, a screenshot, a URL. The grid fills itself.
Propose, don’t ask
Suggest the chart, the insight and the caption from the data shape.
Post-ready, every size
One export gives 16:9, 1:1 and 9:16 with platform safe zones checked.
Every post is a loop
Handle badge, share page with “remix”, monthly series reminders.

NewPaste-anything intakeSpreadsheet cells, “sales went from 12k to 34k”, a screenshot of a table or a public sheet link → parsed into rows, units detected (k, M, %, currency).
NewChart suggestionsThree ranked looks from the data shape: two points → before/after; dates → line; parts summing to 100 → donut; ranked list → bars.
NewInsight chipsAuto-computed facts (largest, delta, share, average) you tap to add as a callout on the chart or a line in the caption.
NewCaption composerA post caption drafted from title + insights, tone toggle (plain / punchy / analyst), hashtags off by default. Copies with the PNG.
NewExport setOne click renders 16:9 + 1:1 + 9:16 (+ 4:3) into a zip, each checked against X, LinkedIn and Instagram safe zones.
NewBrand kitPalette, font pair, logo corner and handle saved once; “Apply my brand” on any template. Colour-blind-safe variant generated automatically.
NewShare page + remixPublic link shows the live chart, the caption and a “Remix with your numbers” button that opens the editor with this look. Views counted.
NewMonthly seriesMark a chart as recurring; next month a card asks for the new numbers and shows last month faded behind for comparison.
ImprovedKeyboard-fast gridTab/Enter navigation, paste a column, ⌘↑↓ reorder, ⌘D duplicate row, unit column, inline sort and “as % of total”.
ImprovedEditor layoutData left, post centre at true size, style right; export fixed top-right. Seven header buttons → two. ⌘K command palette for everything else.
ImprovedAccessibility checkContrast of labels on bars, minimum text size at export, auto alt-text for the post. A single “Post-ready ✓” indicator on the artboard.

Why these, in order of impact
  1. Intake removes the biggest drop-off: typing numbers into fields. Paste is the universal verb.
  2. Suggestions + insights make the product feel expert; the user confirms rather than decides.
  3. Export set + caption finish the actual job, which is posting, not downloading.
  4. Share page + remix is the growth loop; every published chart recruits the next user.
  5. Series + brand turn a one-off into a habit and make the second post faster than the first.

Honest limits: screenshot reading and caption drafting need a model call or an on-device library; everything else is plain browser code. No account is ever required; sign-in only adds sync.
