# ChartGenie Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild chartgenie.xyz as a local-first publishing tool: paste → suggestions → post-ready export set → share link that unfurls → remix, with the design's identity and a single chart renderer.

**Architecture:** A chart engine (`src/chart/`) turns one `ChartSpec` into our own frame (title, badge, footer, callouts) around an Apache ECharts plot (SVG renderer, `animation:false`), and renders it identically in the editor, in the export worker, and in a Vercel Node function for link cards (ECharts SSR: `init(null,null,{renderer:'svg',ssr:true})` + `renderToSVGString()`, verified on 6.1.0). Screens are TanStack Router file routes over a Zustand document store with undo; documents persist in Dexie. No accounts, no stored server state.

**Tech Stack:** React 19 + React Compiler, Vite 8, TypeScript 6 strict, TanStack Router, Zustand + Immer + zundo, Dexie 4, Apache ECharts 6 (tree-shaken, SVG renderer) + d3-array, culori, apca-w3, @resvg/resvg-wasm (browser worker) + @resvg/resvg-js (server), JSZip, cmdk, vite-plugin-pwa, @fontsource-variable (Bricolage Grotesque, Geist, Geist Mono), zod, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-27-chartgenie-redesign-design.md`

## Global Constraints

- Free, no account, saved in this browser. No server stores chart content. Copy never says "synced", "view count", "we'll remind you", "AI-powered", "never leaves your browser", "100% private" (enforced by `src/test/release-claims.test.ts`).
- No mock or demo data presented as real. The only seeded rows are the sample dataset, labelled "sample". No fabricated recent charts, shared links, view counts, or handles. "@Hussain" never appears in code.
- Never delete files: `git mv` retired files into `.archive/<date>/` (gitignored, kept on disk) and remove them from the tree with `git rm --cached` only after the move.
- Chart type count in copy is always derived from `CHART_TYPES.length` (19 after Task 9).
- Bundle budgets: entry chunk ≤ 150 KB gzip; the ECharts chunk ≤ 240 KB gzip and loaded only by routes that draw a chart; export worker, resvg wasm, JSZip, cmdk lazy-loaded.
- Every screen verified in the browser at 1440 px and 390 px before its task is closed; 16 px side gutter on phones, no horizontal scroll, tap targets ≥ 44 px.
- Fonts self-hosted via @fontsource-variable; no Google Fonts request.
- All commits end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- No `.github/workflows`. `scripts/check.sh` is the gate.

## Review Focus

1. **Paste of 500+ rows or a 2 MB CSV** — the grid and the renderer must stay responsive (virtualised rows, chart caps at 60 marks with a "showing top 60" note). Test in Task 15 (grid) and Task 6 (row cap).
2. **A share URL longer than 8 KB** (many rows, long captions) — must fall back to `#state` with a generic card instead of a 414 from Vercel. Test in Task 20.
3. **Storage blocked (private mode, quota exceeded)** — Dexie open fails; the app must still edit and export, show "not saved in this browser", and never throw. Test in Task 12.
4. **Values with mixed units or negatives** ("-12%", "$1.2k", "3,400") — parser must keep the unit consistent per column and negatives must render (bars below zero, funnel refuses with a message). Test in Task 13 and Task 7.
5. **Legacy `#state` links from the current product** (base64 JSON with `schemeId`, `chartType`) — must open in the new editor with an equivalent palette. Test in Task 11.
